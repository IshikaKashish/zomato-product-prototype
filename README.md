## 📌 Project Overview
This project covers an end-to-end teardown of Zomato’s core user journey (discovery, search, filtering, order tracking, and support). By pairing qualitative teardowns with quantitative prioritization, 5 key friction points were mapped to distinct product specs and built into a single, unified prototype.

---

## 🛠️ Key Execution & Scope

- **Problem Discovery:** Audited search, menu navigation, cart management, order tracking, support flows, and post-order cancellations.
- **Prioritization:** Evaluated findings via an **Impact × Frequency × Business Value × Feasibility** matrix to isolate 5 target problems.
- **Product Requirements:** Authored 5 detailed PRDs defining target personas, goals, non-goals, user stories, functional specs, edge cases, and KPI success metrics.
- **UX & Prototyping:** Designed current vs. proposed UX flows and engineered a fully interactive, unified HTML/CSS prototype.

## 🎯 Key Takeaway

A product redesign is more than visual UI improvements - it is about **identifying root friction, validating business impact, establishing concrete functional requirements, and integrating solutions seamlessly into an established user lifecycle.**
